# Changelog

All notable changes to the Sales Overview Dashboard will be documented here.

---

## [1.0.0] — 2026-03-22

### Added
- Initial release of the Sales Overview Dashboard
- Single-page report with 1280×720 canvas
- 4 regional panels: Central, East, South, West
  - Dynamic Title card per region
  - Current Year (CY) Total Sales KPI card
  - Previous Year (PY) KPI Sales card
  - Monthly Clustered Column Chart (Month vs Total Sales)
- Dynamic Metric Slicer to switch between KPIs
- Year Slicer for time-based filtering
- U.S. Map visual showing sales by State/Province and Region
- Horizontal Bar Chart for regional sales comparison
- Pivot Table with full CY / PY / YoY breakdown for Sales, Profit, and Quantity
- Note added for expected "No Data" behavior when 2021 is selected (no prior-year data)
- Applied CY26SU02 Power BI base theme
